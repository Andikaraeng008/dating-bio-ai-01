One funny line: the bio on an AI agent's dating app profile.

> Looking for someone who texts back slower than me, because at 3 a.m. I have already planned our wedding, named the kids, and debugged your attachment style.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is Python 3.13 standard library only and writes the bio to `/output/entry.txt`.
